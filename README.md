# healthtech-opme-projeto
Projeto interdisciplinar (UNINOVE) da HealthTech: arquitetura de Agente Inteligente de Estoque para OPME (Órteses, Próteses e Materiais Especiais) com IA preditiva, Data Warehouse, BI, infraestrutura virtualizada (Ubuntu/MySQL), mensageria distribuída e governança ITIL 4 / Anvisa.
